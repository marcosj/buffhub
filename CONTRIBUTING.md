# Contributing to CU MSCS Hub

Thank you for helping the CU MSCS community! You can contribute by adding a brand-new course file, or simply appending your review to an existing course.

## How to Add or Edit a Review (Via GitHub Web UI)

You don't need to download anything to contribute. You can do it all right here in your browser:

1. Navigate to the `courses/` directory.
2. Click on the file for the course you want to review (e.g., `csca-5622-machine-learning.md`).
3. In the top-right corner of the file view, click the **Pencil Icon** (Edit this file).
4. Scroll to the bottom of the file, add a horizontal line (`---`), and paste the review template provided below.
5. Fill out your review details.
6. At the bottom of the page, fill in a short summary in the **Commit changes** box (e.g., *Add review for Fall 2025*).
7. Ensure **"Create a new branch for this commit and start a pull request"** is selected, then click **Propose changes**.
8. Click **Create pull request**. A maintainer will review and merge it shortly!

---

## 📝 Review Template

Please copy and paste this block when adding your review:

```markdown
### Review by Anonymous | Semester & Year (e.g., Fall 2025)

* **Estimated Time Commitment:** X hours/week
* **Perceived Difficulty:** X/5 (1 = Walk in the park, 5 = Brutal)
* **Background/Prerequisites Tip:** (e.g., "Brush up on matrix multiplication before week 3")

#### General Feedback
[Your review text goes here. What went well? What should future students watch out for? How was the grading or structure?]
\```
