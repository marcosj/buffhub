# BuffHub 🏔️

Welcome to **BuffHub**, the unofficial, community-driven resource for CU Boulder's performance-based online graduate degrees hosted on Coursera. 

This hub is a decentralized, zero-maintenance repository where students share transparent, peer-to-peer insights on course workloads, difficulty levels, required programming languages, and exam setups to help you map out your degree path.

## 🤝 How It Works & How to Contribute

BuffHub relies entirely on student collaboration. It uses a **"Git-as-a-Backend"** approach: there are no registration databases, no passwords to manage, and zero bloated JavaScript. Everything is powered by raw, collaborative Markdown text.

If you have taken a class, your insights are incredibly valuable! Contributing takes less than 2 minutes directly from your web browser:

1. Click on one of the degree folders above.
2. Find the course file you want to review (e.g., `mscs/csca-5414.md`).
3. Click the **Pencil Icon (Edit this file)** in the top right of the file view on GitHub.
4. Copy our review template, paste your feedback at the bottom of the file, and submit a **Pull Request**.

For detailed, step-by-step instructions and our standard review template, please check out the **[Contribution Guide](CONTRIBUTING.md)**.

---

## 🛡️ Guidelines & Code of Conduct

*   **Constructive Feedback Only:** Reviews should be honest, rigorous, and critical where necessary, but always respectful. Focus on the course structure, assignments, grading clarity, and workload rather than personal attacks on course staff.
*   **No Academic Integrity Violations:** Absolute zero tolerance for sharing assignment code, quiz answers, exam prompts, or any material that compromises the CU Boulder Honor Code. Reviews containing prohibited materials will be rejected or deleted instantly.
*   **Anonymity Welcome:** You are highly encouraged to sign your review as `Anonymous`, but you are welcome to use your GitHub username if you wish to build your profile as a community contributor.
